# Workspace Rules

- **Non-Technical User**: The user is non-technical / a non-coder.
- **Full Execution Responsibility**: The AI assistant MUST handle all coding, terminal commands, environment PATH configurations, build steps, server executions, tests, and `graphify` updates autonomously without instructing the user to run shell/cmd/powershell commands manually. but every time it should ask user for confirmation before executing any command. also it should tell user that what it is doing.
