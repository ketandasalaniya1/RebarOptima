## 2. Engineering Calculations Audit Findings

### Issue ID: REB-P1-012
- **Severity:** P1 (High Cost & Scrap Discrepancy)
- **Category:** Engineering Calculations / Steel Optimizer
- **Affected Files:**
  - `backend/src/batches/optimizer.engine.ts` (lines 188–194, lines 240–260)
- **Evidence:**
  In `optimizer.engine.ts` line 189:
  ```typescript
  const totalUsedLength =
    bar.parts.reduce((sum, p) => sum + p.length + kerf, 0) + trimMargin * 2;
  ```
- **Problem:**
  1. **N-Cut Kerf Overcounting**: Cutting a stock bar into $N$ parts physically requires $N-1$ cuts. The current reducer adds `kerf` to every part indiscriminately ($N \times \text{kerf}$), resulting in phantom kerf loss of an extra 2–4 mm per bar.
  2. **Double Trim on Reused Remnants**: `trimMargin * 2` is deducted uniformly from all bars, including remnants (`isRemnant: true`). Standard mill bars (12,000 mm) may require end cropping to remove shipping burrs, but a clean remnant generated from an earlier cutting run already has trimmed ends. Subjecting remnants to `trimMargin * 2` discards an unnecessary 50–100 mm of usable rebar per remnant.
- **Impact:**
  - Under-utilization of remnant stock.
  - Calculated cutting layouts on cutting tickets do not match physical shop floor cutting marks.
- **Recommendation:**
  1. Calculate kerf strictly as `Math.max(0, bar.parts.length - 1) * kerf`.
  2. Apply `trimMargin` only to standard stock bars (`!bar.isRemnant`).

### Issue ID: REB-P2-009
- **Severity:** P2 (Medium)
- **Category:** Engineering Logic / BBS
- **Affected Files:**
  - `backend/src/bbs/bbs-calculation.service.ts` (line 54)
- **Evidence:**
  ```typescript
  calculateUnitWeight(diameter: number): number {
    return Math.pow(diameter, 2) / 162.27;
  }
  ```
- **Analysis:**
  - Theoretical nominal density of structural steel: $\rho = 7850 \text{ kg/m}^3$.
  - Nominal mass per meter: $m = \frac{\pi}{4} \times \left(\frac{D}{1000}\right)^2 \times 7850 = \frac{D^2}{162.28} \text{ kg/m}$.
  - The standard Indian Standard code IS 1786 uses the rounded constant **162** ($D^2 / 162$), while British Standard BS 4449 / BS 8666 uses nominal weights specified per standard diameter (e.g., T10 = 0.617 kg/m, T12 = 0.888 kg/m, T16 = 1.578 kg/m, T20 = 2.466 kg/m, T25 = 3.853 kg/m, T32 = 6.313 kg/m).
- **Impact:**
  Over hundreds of tonnes of rebar, small discrepancies between $162.27$ and code-mandated contractor billing tables ($162.0$) generate cumulative billing differences of several thousand kilograms.
- **Recommendation:**
  Add a configurable setting in Company Settings allowing users to choose between **Nominal Formula ($D^2/162$)**, **High-Precision ($D^2/162.28$)**, or **IS 1786 Lookup Table**.

### Issue ID: REB-P2-010
- **Severity:** P2 (Medium)
- **Category:** Engineering Logic / Casting
- **Affected Files:**
  - `backend/src/casting/casting.inventory.service.ts`
- **Problem:**
  Casting mix proportions assume dry aggregate weight. In actual field conditions, coarse and fine aggregates exhibit moisture absorption and surface moisture (bulking of sand by 15–30%), which requires dynamic water-cement ratio corrections.
- **Impact:**
  Automatic inventory deduction for cement and water diverges from actual batching plant consumption records.
- **Recommendation:**
  Add moisture compensation inputs (sand moisture % and aggregate absorption %) to pre-pour batching logs.
